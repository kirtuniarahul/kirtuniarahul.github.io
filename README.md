# Kirtunia Rahul — Jekyll GitHub Pages Portfolio

This version uses the GitHub Pages Cayman Jekyll theme.

## Important
Delete your old `index.html` before using this version. Otherwise it can override `index.md`.

## Main files
- `_config.yml` — theme/site settings
- `index.md` — homepage content
- `about.md` — About page
- `projects.md` — Projects page
- `research.md` — Research page
- `assets/css/style.scss` — custom appearance
- `assets/images/` — images
- `assets/videos/` — videos

Upload all contents to the root of your `kirtuniarahul.github.io` repository.
