# Kirtunia Rahul — Multi-Page Engineering Portfolio

This version uses separate Markdown files/pages for each major section.

## Pages

- `index.md` → Home
- `education.md` → `/education/`
- `research.md` → `/research/`
- `experience.md` → `/experience/`
- `publications.md` → `/publications/`

The navigation bar appears on every page.

## Main supporting files

- `_layouts/default.html` → shared header, navigation, footer
- `assets/css/style.css` → visual design
- `assets/js/main.js` → animated engineering background
- `assets/images/` → images
- `assets/videos/` → videos

## Editing

To modify Education, edit `education.md`.

To modify Research Projects, edit `research.md`.

To modify Experience, edit `experience.md`.

To modify Publications, edit `publications.md`.

To modify the homepage, edit `index.md`.

## GitHub Pages

Upload the contents of this folder to the root of your `kirtuniarahul.github.io` repository.

Remove or rename any old `index.html`.

Use:

Settings → Pages → Deploy from a branch → main → / (root)
